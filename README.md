# Chikyu-gata Historical Globe

Chikyu-gata Historical Globe is a lightweight 3D historical map viewer for
exploring world borders, historical eras, and Earth-history milestones on a
rotating globe.

The project intentionally uses Three.js and local GeoJSON data instead of a
heavy tile service. It is designed to be easy to run, inspect, and modify as an
open educational visualization.

## Why This Exists

History maps are often locked inside static images or heavy web services. This
project aims to make a local-first globe where students, creators, and map
tinkerers can inspect the data, adjust eras, and build their own historical
visualizations.

## Features

- Three.js globe with mouse, wheel, pinch, and button controls
- era slider from deep Earth history to modern historical boundaries
- lightweight GeoJSON border layers for representative historical years
- location click details for historical region, sovereign entity, ownership, and boundary confidence
- Earth-history and life-history markers with environment/biology notes
- automatic information-density changes for far, normal, and close views
- browser mode through a tiny local Python server
- Electron portable build configuration for Windows

## Quick Start

On Windows, double-click:

```text
start-map.bat
```

The launcher opens a local URL such as `http://127.0.0.1:4173/`. If port 4173
is already in use, it automatically tries the next available port. The included
`server.py` only serves local files and sets correct MIME types for `.js` and
`.geojson`.

## Electron App

Install dependencies and start the Electron wrapper:

```powershell
npm install
npm start
```

Build a portable Windows release:

```powershell
npm run dist
```

Release outputs are ignored by Git.

## Updating Historical Border Data

The reduced GeoJSON files in `data/borders/` are generated by
`tools/prepare-data.mjs`.

```powershell
node tools\prepare-data.mjs
```

To add a representative year, edit the `eras` array in
`tools/prepare-data.mjs`. Existing Earth-history and life-history era metadata
in `data/eras.json` is preserved.

## Data And Accuracy

Historical borders are approximate and can be disputed, especially before modern
treaty boundaries. This project treats the map as an educational visualization,
not an authoritative legal source.

Boundary data is derived from `historical-basemaps`; see
`THIRD_PARTY_NOTICES.md` for source and license details.

## Project Status

This is an actively maintained prototype. The current focus is improving the
historical timeline, reducing the data size, and making the globe useful for
education, streaming, and creative world-history explanations.
