# 地球型歴史地図

軽量な3D地球儀で、年代ごとのベクター国境を切り替えて見られるWebアプリです。CesiumJSではなくThree.jsを使い、画像タイルや地形を読み込まない構成にしています。

## 起動

`start-map.bat` をダブルクリックしてください。

ブラウザが `http://127.0.0.1:4173/` を開きます。4173番ポートが使われている場合は自動で次の空きポートを使います。`server.py` は `.js` や `.geojson` のMIMEを明示するための小さなローカルサーバです。

## 内容

- 3D地球儀の回転、ピンチ/ホイール/ボタンでの拡大縮小
- 年代スライダー: 地球誕生の約45.4億年前から現代までの代表時代
- 地球史・生物史の時代では2010年の世界地図ベクターを背景に表示し、代表地点マーカーと環境/生物情報を表示
- GeoJSONベクター国境の表示
- 地点クリックによる当時の地域名・宗主国/主体・所属・国境精度の表示
- 遠景/標準/近景の3段階で情報量を切り替え

## データ更新

国境データを作り直す場合は、Node.jsが入った環境で以下を実行します。

```powershell
node tools\prepare-data.mjs
```

`tools/prepare-data.mjs` の `eras` 配列に年を追加すると、対応する `world_年.geojson` を取得して `data/borders` に軽量化データを生成します。既存の地球史・生物史の時代情報は保持されます。
